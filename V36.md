# v36

Текущая версия Avito status bot.

- без промежуточного сообщения «собираю данные»;
- готовый результат отправляется только после полного сбора;
- `/notify` — дни уведомлений;
- `/notify_times` — до 8 времён уведомлений;
- `/delete_after` — настройка автоудаления сообщений;
- очередь автоудаления хранится в `/app/data/message_delete_queue.json` и переживает перезапуск контейнера;
- даты регулярных платежей сохраняются в `/app/data/payment_state.json`.

`bot.py` загружает исходник v36 из `_v36_parts/part01.txt` … `_v36_parts/part08.txt`.
