# nmavitobot v39

Изменения:

- у каждого типа сборщика своё расписание уведомлений: «Вся информация», «Баланс», «Объявления»;
- для каждого типа отдельно задаются дни недели, включение/выключение и до 8 времён;
- ввод времени сделан напрямую: после «➕ Добавить время» Telegram открывает поле ввода;
- время вводится обычным сообщением в формате `ЧЧ:ММ`, например `09:15`;
- существующее время можно нажать и заменить таким же прямым вводом;
- поддерживается `отмена`;
- формат проверяется строго в диапазоне `00:00–23:59`;
- старый интерфейс с `+1 ч / -1 ч / +1 мин / -1 мин` удалён;
- промежуточных сообщений при сборе данных нет — приходит только готовый результат;
- настройки расписаний и автоудаления сохраняются в `/app/data`.

Запуск на BotHost: `python bot.py`.
