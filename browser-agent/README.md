# Avito CPA Watch 1.2 — Edge direct

Эта версия предназначена только для диагностики Edge.

Отличия:
- нет service worker;
- нет alarms;
- нет обмена сообщениями между popup и background;
- кнопка сама выполняет chrome.scripting.executeScript в активной вкладке Avito;
- код исполняется в MAIN world страницы;
- есть жёсткий таймаут 12 секунд;
- при ошибке причина выводится прямо в popup.

Установка:
1. Удалить/отключить старую копию расширения.
2. Распаковать архив.
3. edge://extensions.
4. Включить режим разработчика.
5. «Загрузить распакованное».
6. Выбрать папку avito_cpa_watch_v1_2_edge_direct.
7. Сделать вкладку Avito активной.
8. Открыть расширение и нажать «Проверить сейчас».
