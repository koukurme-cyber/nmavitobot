# Avito CPA Watch v1.1

Исправление совместимости с Microsoft Edge.

Главное изменение: запрос к Avito сначала выполняется прямо внутри открытой авторизованной вкладки www.avito.ru через chrome.scripting.executeScript. Это обходит отличие Edge в обработке cookies для background service worker.

Также добавлен таймаут: кнопка «Проверяю…» больше не должна зависать бесконечно.

Установка в Edge:
1. edge://extensions
2. Режим разработчика
3. Удалить/отключить старую копию расширения
4. Загрузить распакованное расширение v1.1
5. Открыть любую страницу www.avito.ru в авторизованной сессии
6. Нажать «Проверить сейчас»

При успешной проверке источник должен быть avito-tab.
