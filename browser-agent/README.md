# Avito CPA Watch 1.3 — Edge fix

Исправлено:
- убран параметр `world: "MAIN"` из `chrome.scripting.executeScript`;
- именно он вызывал в Edge ошибку `Unexpected property: 'world'`;
- запрос по-прежнему выполняется из активной авторизованной вкладки Avito;
- жёсткий таймаут 12 секунд и вывод текста ошибки сохранены.

Установка:
1. Отключить/удалить версию 1.2.
2. Распаковать архив.
3. Открыть `edge://extensions`.
4. Включить режим разработчика.
5. Нажать «Загрузить распакованное».
6. Выбрать папку `avito_cpa_watch_v1_3_edge`.
7. Сделать вкладку Avito активной.
8. Нажать «Проверить сейчас».
