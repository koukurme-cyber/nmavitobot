# Avito CPA Watch v1

Отдельное Chrome/Chromium-расширение. Рабочий Telegram-бот v41 не меняется.

## Что делает

- раз в минуту проверяет:
  `https://www.avito.ru/web/3/tariff/cpa/profile?entryPoint=desktop_profile`
- использует текущую авторизованную браузерную сессию Avito;
- читает:
  - `advanceBalance`;
  - `advanceThreshold`;
  - `cpaAlert`;
- считает показы остановленными, если:
  - `advanceBalance < advanceThreshold`, или
  - `cpaAlert` = `CPA_NOT_ENOUGH_ADVANCE`, или
  - `cpaAlert` = `CPA_VIEWS_PAUSED`;
- отправляет одно Telegram-сообщение при остановке;
- не спамит повторно, пока состояние не изменилось;
- отправляет одно сообщение после восстановления.

## Установка

1. Распаковать архив в отдельную постоянную папку.
2. Chrome → `chrome://extensions`.
3. Включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку `avito_cpa_watch_v1`.
6. Открыть параметры расширения и заполнить настройки.
7. В браузере должен быть выполнен вход в нужный аккаунт Avito.

Для каждого Avito-аккаунта удобнее использовать отдельный профиль Chrome и отдельную
установку расширения с собственным названием аккаунта.

## Telegram

Расширению нужны:
- Bot Token текущего Telegram-бота;
- Chat ID.

Токен сохраняется в `chrome.storage.local`, то есть только локально в текущем профиле
браузера. В исходниках токена нет. В GitHub секреты не загружаются.

Отправка через Bot API `sendMessage` не использует `getUpdates` и не создаёт
конфликт `409` с рабочим ботом v41.

## Проверка

В настройках:
- «Тест Telegram» — проверяет отправку сообщения;
- «Проверить Avito» — сразу показывает фактические значения
  `advanceBalance`, `advanceThreshold`, `cpaAlert`.

Если фоновый запрос расширения не проходит, оно пробует выполнить тот же запрос через
любую открытую вкладку `www.avito.ru`.

## Ограничение

Мониторинг работает, пока Chrome запущен. Если компьютер выключен или Chrome полностью
закрыт, проверки не выполняются.
