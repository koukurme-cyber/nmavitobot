# nmavitobot v42

Диагностика динамического порога остановки показов.

Из HAR страницы Avito Pro найден источник:

`GET https://www.avito.ru/web/3/tariff/cpa/profile?entryPoint=desktop_profile`

В состоянии страницы:
- `result.advanceThreshold` — динамический порог остановки показов, в копейках;
- `result.advanceBalance` — текущий аванс, в копейках;
- `result.cpaAlert` — состояние CPA/показов.

В предоставленном HAR:
- `advanceThreshold = 89930` → 899,30 ₽;
- `advanceBalance = 180040` → 1 800,40 ₽.

v42 для CPA-аккаунтов делает диагностический GET к этому endpoint с обычным OAuth Bearer бота, без browser cookies. Пользовательский вывод не меняется.

В логах искать:
`CPA web threshold v42 aggregaty: ...`
`CPA web threshold v42 avmex: ...`
`CPA web threshold v42 tir: ...`
