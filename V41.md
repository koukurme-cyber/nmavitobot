# nmavitobot v41

Изменения:

- пользовательские настройки уведомлений временно убраны;
- автоматические уведомления работают только по будням;
- 08:00 — `status_all`;
- 08:40 — `balance_all`;
- 10:00–16:00 каждый час — `balance_all`;
- все автоматические уведомления удаляются через 30 минут;
- `/delete_after` сохранён только для обычных ручных сообщений и команд пользователя;
- автоматические уведомления не зависят от `/delete_after`;
- промежуточных сообщений при ручном сборе нет — приходит только готовый результат.

Запуск на BotHost: `python bot.py`.
