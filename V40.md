# nmavitobot v40

Hotfix проблемной v39.

Исправлено падение после запуска:

`ERROR: name '_send_help' is not defined`

Причина: при удалении старого редактора времени с кнопками `+/-` в v39 был случайно вырезан соседний служебный блок.

В v40 восстановлены:

- `_send_help`;
- `_commands_help`;
- `_handle_help_callback`;
- настройки `/delete_after`;
- `_handle_delete_callback`;
- `_parse_direct_command`;
- `send_query`.

Прямой ввод времени `ЧЧ:ММ` из v39 сохранён.

Перед публикацией локально проверены синтаксис и неопределённые вызываемые имена: ошибок не найдено.

Запуск на BotHost: `python bot.py`.
