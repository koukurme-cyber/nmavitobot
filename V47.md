# nmavitobot v47

Предупреждения заменяют друг друга:
- новое предупреждение того же вида по тому же аккаунту (аванс / объявления) удаляет предыдущее;
- если аванс пополнили выше порога — последнее предупреждение по аккаунту удаляется.

ID отправленных предупреждений хранятся в `DATA_DIR/alert_state.json`.
Telegram даёт боту удалять свои сообщения только в течение 48 часов.
