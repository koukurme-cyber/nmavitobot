# nmavitobot v43

В v42 диагностика динамического порога запускалась только во время финансового сбора, поэтому после обычного перезапуска в логах была только строка `Bot started v42`.

В v43 при старте запускается лёгкий фоновый probe для CPA-аккаунтов:
- aggregaty;
- avmex;
- tir.

Он проверяет найденный endpoint:
`GET /web/3/tariff/cpa/profile?entryPoint=desktop_profile`

Без browser cookies — только с обычным OAuth Bearer.

В логах сразу после запуска должны появиться строки:
`CPA threshold startup probe v43 ...`

Нужные поля:
- `status`;
- `advanceThreshold`;
- `advanceBalance`;
- `cpaAlert`.
