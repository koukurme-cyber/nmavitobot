# nmavitobot v10

Пять Avito-аккаунтов:
- Агрегаты — кошелёк + аванс
- Авмекс — кошелёк + аванс
- Надёжные Машины (оранжевые) — кошелёк + остаток размещений
- Надёжные машины (синие) — кошелёк + остаток размещений
- ТИР — кошелёк + аванс

Также:
- статусы объявлений;
- дата окончания тарифа, если Avito её отдаёт;
- следующий запланированный тариф: дата + стоимость, если Avito его отдаёт;
- сообщение удаляется через 10 минут;
- кнопка «Обновить» удалена;
- `/start` и `/status` сразу показывают кэш, обновление идёт в фоне.

Секреты в репозиторий не добавлять.


## v12: сначала финансы, потом объявления

Обновление теперь идёт в две фазы:

1. Сначала по всем аккаунтам собираются кошелёк, аванс/остаток размещений и тарифные данные.
2. Только после этого начинается тяжёлый обход всех страниц объявлений.

Это позволяет быстро получить диагностические и финансовые данные по Авмексу, ТИР и другим аккаунтам, не ожидая полного обхода тысяч объявлений предыдущего аккаунта.


## v13: исправлен показатель «Аванс»

Для CPA-аккаунтов показатель «Аванс» теперь берётся из поля `balance`
метода `/cpa/v2/balanceInfo`.

Поле `advance` больше не используется для отображения, потому что оно
не соответствует цифре «Аванс» в интерфейсе Avito Pro.

Сумма приходит в копейках и преобразуется в целые рубли без округления вверх,
как в интерфейсе Avito Pro.


## v14: двухэтапное обновление Telegram

Раньше финансы собирались первыми, но сообщение в Telegram редактировалось только
после полного обхода всех объявлений. Поэтому после строки `Financial phase completed`
визуально казалось, что бот завис.

Теперь:
1. После завершения финансовой фазы сообщение сразу редактируется.
2. Пока считаются объявления, в блоках показывается `Объявления обновляются…`.
3. После полного обхода объявлений то же сообщение редактируется второй раз.


## v15: подписки CPA-аккаунтов

Добавлены известные подписки:
- Агрегаты — Максимальная
- Авмекс — Расширенная
- ТИР — Расширенная

Для этих CPA-аккаунтов больше не вызывается `/tariff/info/1`, потому что этот
метод возвращает 404 и относится к другому типу тарифа. Это убирает лишние
ошибки из логов и немного ускоряет финансовую фазу.

Название подписки хранится в `config.json` и выводится строкой `Подписка: ...`.
